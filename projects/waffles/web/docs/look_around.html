Looking around

This document hilights some of the more important tools that you will find to work with in this library.

One of the most common operations in machine learning is to optimize something. The WOptimizer class provides a base class for optimization techniques. Some of the classes that inherrit from WOptimizer include WBruteForceSearch, WAnnealing, WEvolutionaryOptimizer, WHillClimber, WParticleSwarm, WRandomSearch, etc. In order to use these classes for optimization, you must create a class that inherits from WTargetFunction. Your task for the target function is to evaluate the error associated with a candidate vector. You can then plug in any of these optimization techniques to try to find a vector that evaluates to have low error for your particular task. Since some optimizers are better suited for some tasks than others, you might as well try them all and go with the one that works the best. (In my experience, evolutionary optimization is used with more applications than it deserves, and hill climbing often produces surprisingly better results than many people expect. Of course, your mileage may vary, depending on the applications to which you apply it.)

Clustering algorithms inherit from the WClusterer class, which inherits from WTransform. These include WAgglomerativeClusterer, WKMeans, and WKMedoids. These classes all take a matrix as input, and return a class id for each row in the matrix.

Non-linear Dimensionality Reduction algorithms inherit from WManifoldLearner, which also inherits from WTransform. These include WIsomap, WLLE, WManifoldSculpting, and a few others. These methods take a matrix as input, and return a corresponding matrix with fewer columns.

Some other particularly useful classes include WPCA, which implements principal component analysis, and WAttributeSelector, which removes the least salient attributes one-at-a-time, until it can identify the attributes that are most salient for predicting the labels.

Collaborative filtering algorithms inherrit from the WCollaborativeFilter class. These classes are used for building a recommendation system, or for intelligently filling in missing values in data.

Neighbor-finding algorithms inherrit from the WNeighborFinder class. These include WBruteForceNeighborFinder, WKdTree (which finds the nearest neighbors more efficiently), and a few algorithms for intelligently selecting neighbors according to various criteria.

Several graph-based algorithms are provided in the WGraphCut, WFloydWarshall, WDijkstra, WBrandesBetweennessCentrality, and WCycleCut classes.

The WRand class is a particularly useful pseudo-random number generator. It provides methods to draw random values from a plethora of distributions. Implementations of various common statistical distributions are also implemented. These inherrit from WDistribution.

The WPlotWindow and WImage classes are particularly useful for creating visualizations of data.

Many other useful classes are provided for a variety of specific machine learning operations. For a complete list of implemented algorithms, see the API documentation.
